API Documentation

Welcome to the FinEdge Developer Docs. Here you'll find everything you need to integrate our Privacy-Preserving Edge-ML Credit Scoring SDK into your banking application.

1 Authentication

All API requests must be authenticated using your Tenant API Key and a cryptographically signed HMAC payload.

Authorization: Api-Key <your_tenant_api_key>
X-FinEdge-Signature: <hmac_sha256_hex_digest>

2 Submit Edge Metadata

POST /api/v1/score/

This endpoint receives the mathematical vector generated by the Edge SDK. Raw data is never transmitted. The backend verifies the signature and queues the application for Officer Review.

Request Body

{ "device_hash_mask": "a1b2c3d4e5f6...", "tracking_reference": "LOAN-APP-90210", "requested_amount": 2000, "mathematical_vector": { "device_age_days": 365, "utility_sms_count": 24, "battery_deaths_weekly": 1, "saved_contacts_ratio": 0.45, "financial_apps_count": 4, "average_monthly_balance": 45000.50, "lifetime_emi_bounces": 0 } }

3 Poll Application Status

GET /api/v1/application/<application_id>/status/

Poll this endpoint from your mobile app while the user waits for manual officer review. It returns the current workflow step and the final decision badge once the officer manually triggers the FinEdge TrustScore.

Response

{ "status": "SCORE_COMPUTED", "trust_score": 812, "decision": { "label": "Approved via Edge-ML", "color": "green" } }
